# 从告警通知进入预警页后无法退回行情主页

日期：2026-09-21
涉及版本：0.9.1（versionCode 13）
改动文件：`ui/navigation/AppNavigation.kt`（单文件）

需求原文：

> 通过常驻的告警通知点开预警页无法退回主页

---

## 一、根因

通知的 `contentIntent` 带 `EXTRA_OPEN_ALERTS`，`MainActivity` 读到后透传给 `AppNavHost`，后者把预警页设成**起始页**：

```kotlin
startDestination = if (openAlerts) Routes.ALERTS else Routes.MARKET
```

这么写是为了「从通知栏进入时首帧就落在预警页，避免先闪一下行情列表」—— 目的达到了，但代价是**返回栈里根本没有行情页**：

- 左上角箭头 → `onBack = { navController.popBackStack() }` 返回 `false`，点了没反应；
- 系统返回键 → NavController 也退不动，落到 Activity 的默认行为 → **直接退出应用**。

两条路都回不到行情主页。

## 二、改法

退得动就正常 pop；退不动（`previousBackStackEntry == null`，即预警页就是栈底）就把预警页**换成**行情页：

```kotlin
val leaveAlerts: () -> Unit = {
    if (navController.previousBackStackEntry == null) {
        navController.navigate(Routes.MARKET) {
            popUpTo(Routes.ALERTS) { inclusive = true }
        }
    } else {
        navController.popBackStack()
    }
}
```

要点两条：

1. **系统返回键与左上角箭头共用这一条路径**：`BackHandler(enabled = openAlerts) { leaveAlerts() }` 放在 `composable(Routes.ALERTS)` 里。`enabled` 只在「预警页是起始页」时才为真 —— 否则会抢掉 NavController 正常的 pop（如预警页 → 行情页）。
2. **判断放在调用时而不是组合时**。这是关键：用户从预警页走进编辑页 / Webhook 页时，`BackHandler` 仍处于注册状态（预警页的 composition 在转场期间还没销毁），此时 `previousBackStackEntry` 是预警页、非空，应当照常 pop 一层。若把判断写在组合期（如 `enabled = navController.currentBackStackEntry?.destination?.route == ALERTS`），一旦取值时机不对就会「从编辑页一路跳回主页」。

`popUpTo(ALERTS) { inclusive = true }` 之后栈里只剩行情页，**之后的返回键才是正常的退出语义**（而不是从主页再弹回一个空栈）。

## 三、验证（模拟器实测）

| 路径 | 结果 |
| --- | --- |
| 通知进入预警页 → 左上角箭头 | 行情主页 ✅ |
| 通知进入预警页 → 系统返回键 | 行情主页 ✅ |
| 通知进入 → 预警页 → 编辑页 → 系统返回 | 预警页（未跳过）✅ |
| 主页 → 铃铛 → 预警页 → 编辑页 → 系统返回 | 预警页（原行为未变）✅ |

复现通知入口不必真等告警触发，直接带 extra 冷启动即可：

```bash
adb shell am force-stop com.waxilo.marketmonitor
adb shell am start -n com.waxilo.marketmonitor/.MainActivity \
  --ez com.waxilo.marketmonitor.OPEN_ALERTS true
```

## 四、遗留

`MainActivity` 没有 `onNewIntent`，manifest 也未设 `launchMode`（默认 `standard`）。因此**应用已在运行时**点通知会新建一个 Activity 实例，而不是复用现有实例跳到预警页 —— 这一条本次未动（用户报的是返回问题，且改动会牵动任务栈语义），若后续要改，需同时加 `launchMode="singleTop"` 与 `onNewIntent` 里的导航。
