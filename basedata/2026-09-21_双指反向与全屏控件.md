# 双指反向捏合修复 + 全屏周期/指标控件

日期：2026-09-21
涉及版本：未发版（工作区改动，versionName 仍为 0.4.0 / versionCode 6）

## 一、双指反向移动失效

需求原文：*"图表上进行双指操作时，我如果反向移动，是会出现问题的，不允许反向移动"*。

### 根因

不在「反向」本身，而在 `ui/chart/ChartGesture.kt` 的缩放累加器 `accumulatePinch` 里的**欠账**：

- 为防一帧冲过头，它把每帧提交的根数钳在 ±1；
- 快速捏合时每帧折算量有十几到几十根，超出的部分留在 `remainder` 里逐帧消化；
- 于是快速张开会攒下一笔**负向欠账**（实测 5 帧可攒到 -75 根）。

手指反向时，这笔旧方向的欠账要先被「还清」才轮到新方向 —— 图上表现为**手已经往回收，图还在朝原方向继续放大**。慢速反向时尤其明显（反向折算量每帧只有几根，要十几帧才抵完欠账）。

这与代码里已有的 `ValueRange.panLimit` 是同一类问题，那里的注释写得很清楚：*"钳的是累积量本身而不是渲染结果：否则拖到边界后 pricePan 还在涨，反向拖要先走完这段空行程才见效，手感像卡住了"*。

### 修法

`accumulatePinch` 中，本帧折算量与余量**异号**时先把余量清零：

```kotlin
val folded = (bars * (ratio - 1.0)).toFloat()
val carried = if (remainder * folded < 0f) 0f else remainder
val total = carried + folded
```

- 异号 = 手指改了方向 → 旧方向的欠账作废，反向第一帧就换向；
- 本帧折算量为 0（`factor == 1`，手指停住）时没有方向信息，余量原样结转继续逐帧消化 —— 保住了「快速捏合松手前那几根不丢」的既有行为；
- 每帧 ±1 的钳制、`reportApplied` 校正、`MIN_RATIO/MAX_RATIO` 折叠都没动。

### 测试

`app/src/test/java/com/waxilo/marketmonitor/ui/chart/ChartModelTest.kt` 新增 3 条：

- `反向捏合第一帧就换向而不是先还清欠账`：单元级，断言反向第一帧提交 +1；
- `本帧折算量为零时余量继续逐帧消化`：守住「停住时不清零」的边界；
- `快速张开后反向合拢图上必须立刻开始往回走`：逐帧复刻真实手势（张开 4 帧 → 合拢 4 帧），断言反向第一帧的可见根数必须比上一帧更宽。

全套 86 项单测通过，原先钉住累加器行为（每帧最多一根、不冲过头、跨阈值不丢零头、非法因子不破坏零头）的测试全部保持通过。

## 二、全屏支持周期切换与指标选择

需求原文：*"全屏时应该支持指标选择、周期切换"*。

### 问题

全屏是横屏，竖屏那套控件（周期条、叠加指标条、副图条）整块被图表顶掉了，顶部只剩「划线 / 清除线 / 退出全屏」。用户想换个周期必须先退出全屏、改完、再进来。

### 实现

`ui/detail/DetailScreen.kt` 的 `FullscreenChart`：

- 顶部按钮排新增两个 chip：**周期**（chip 文字即当前周期，如「1d」）与**指标**；两者与「划线」并列，选中态复用反色块。
- 两个浮层**互斥**、按需展开：点当前已展开的那个 = 收起，点另一个 = 换过去（`FullscreenPanel.toggled`）。
- 浮层锚在**底部**：顶部要留给图例带与按钮排，底部只有时间轴，被临时盖住不影响看形态。
- 周期浮层复用 `IntervalSelector`，选完自动收起（单选）；指标浮层复用 `IndicatorBar`，可连续开关（多选）。
- 面板状态用 `rememberSaveable` 挂在 `FullscreenChart` 内部：退出全屏再进来回到普通看图态，不带状态。

### 附带：两个控件新增 `compact` 模式

首版直接复用竖屏的两行式（两条小标题 + 两行方块），实机发现它在横屏里要吃掉**近 40% 屏高**，把副图区整个盖住 —— 开副图却看不见副图，等于白开。

于是给 `IntervalSelector` / `IndicatorBar` 加 `compact: Boolean = false`：

- 竖屏默认走原来的两行式，行为不变；
- 全屏走单行横滚：`叠加 MA5…MA60 BOLL │ 副图 VOL MACD RSI KDJ`，分组小标题降级成行内标签（新增 `InlineLabel`），组间用 1dp 竖线分隔；
- 浮层高度降到约屏高 10%，只压住时间轴一带。
