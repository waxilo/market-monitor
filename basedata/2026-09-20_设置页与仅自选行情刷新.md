# 设置页实现 + 行情改为「仅自选 + 300ms 刷新」

日期：2026-09-20
涉及版本：0.4.0（versionCode 6）

## 一、设置页实现

原先 `Routes.SETTINGS` 是占位 `HintRow`（提示"设置页正在开发"）。本次实现完整设置页。

### 新增文件

- `ui/settings/SettingsViewModel.kt`：状态管理与持久化。
  - 所有 setter 通过私有 `persist { }` 在 `viewModelScope.launch` 内调用 suspend 的 `settings.edit`，避免「suspend 函数不能在非协程 setter 调用」报错。
  - `checkUpdate()` 接线到 `updateRepository`。
- `ui/settings/SettingsScreen.kt`：分组设置列表（通用 / 镜像域名 / 通知 / 预警轮询 / 更新 / 关于）。

### 修改文件

- `ui/navigation/AppNavigation.kt`：把占位替换为 `SettingsScreen(onBack = ...)`，移除 `HintRow` 占位。

### 说明

计价币 `quoteAsset`、默认市场 `defaultMarket`、三个镜像域名、更新检查等后端能力早在 `AppSettings/SettingsDataStore` 就绪，本次仅补齐 UI 接线。

## 二、行情首页改为「仅自选 + 300ms 节流刷新」

需求原文：*"不支持展示所有交易行情，仅在搜索页可以搜索，每次打开应用页只刷新关注的行情，0.3秒对行情刷新一次"*。

### 确认的方案

- 刷新机制：**WS 推送 + 300ms 节流**（不轮询）。
- 首页范围：**仅自选**（移除「行情/ALL」页签，只留自选列表）。

### 修改文件

- `data/repository/MarketRepositoryImpl.kt`
  - 构造函数注入 `watchlist: WatchlistRepository`（`di/AppContainer.kt` 一并传入）。
  - `start()`：由订阅全市场 `!miniTicker@arr` 改为只订阅当前市场自选交易对的 `Streams.miniTicker(symbol)` 流，与 K 线等 `extraStreams` 合并去重后经 `socket.events(market, streams)` 自动换流。
  - `refreshTickers()`：不再全量拉取（REST 权重约 80），改为只刷新自选交易对，逐调用权重只有 1；无自选时直接返回 0。
- `ui/market/MarketViewModel.kt`
  - `MarketTab` 移除 `ALL("行情")`，仅保留 `WATCHLIST("自选")`。
  - `repository.tickers(...)` 流加 `.sample(300)`：WS 实时推送，UI 每 0.3 秒合并一次最新行情。
  - `rows` 改为仅按自选顺序 `mapNotNull` 取出对应 ticker 渲染。
- `ui/market/MarketScreen.kt`
  - 移除 MarketTab 段选（仅保留市场切换 `MarketType`：现货/永续）。
  - 刷新按钮 contentDescription 改为"刷新关注行情"。
  - 空态 `EmptyState` 引导："去搜索添加" → `onOpenSearch`。

### 附带影响

- 搜索页仍可用：数据源 `combine(tickers, instruments, watchlist)` 用 `instruments`（来自 exchangeInfo）可按标的名搜索收藏。
- 因 `refreshTickers` 只刷自选，Room 中非自选 ticker 的缓存仅为历史遗留，首次安装时搜索页可能只有 symbol(通过 exchangeInfo) 而无价格——符合"仅搜索页可搜索"。

### 验证

- `:app:assembleDebug` 构建通过。
- MuMu 模拟器实拍：首页仅市场切换（现货/永续）、无"自选/行情"页签；无自选时正确显示引导空态"还没有关注任何交易对 + 去搜索添加"；离线时显示"网络中断，正在展示最近一次缓存"。
