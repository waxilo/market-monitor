# UI 重构归档（v0.3.0）

- 日期：2026-09-20
- 版本：0.3.0（versionCode 5）
- 范围：全文重构前端 UI（Jetpack Compose Material3），沿 `frontend-skill` / `web-design-guidelines` 通用原则落地到 Compose：单一强调色、强排版层级、可扫描的密集信息、触控与对比度达标。
- 验证：`:app:assembleDebug` 通过；MuMu12 模拟器实拍行情列表 / 空态页。

## 一、设计系统

### 1. Color.kt
- 补全明暗两套 `surfaceContainer*` 分级（Low/Container/High/Highest），背景有清晰表面层级。
- 新增黄色承载文字色 `OnAccent*`：币安黄底上不用默认白字（黄底白字对比不足），改用深棕字。

### 2. Theme.kt
- 映射完整 Material3 ColorScheme（含 surfaceContainer 五档、surfaceBright/Dim、error）。
- 修正对比：`onPrimary` 用深字；浅色 `outline` 由近白 `#D9DCE2` 改为中灰 `#7F7F87`，修复所有 OutlinedButton 边框不可见问题。

### 3. Type.kt
- 补全覆盖页面全部语义层级（title/body/label 三级）。
- 行情数字统一 Monospace，避免刷新列宽抖动；明细值右对齐。

## 二、公共组件（CommonUi.kt）

- 新增统一 `AppBar`（返回键 + 标题 + 副标题 + actions），消除 5 处页面重复手写标题栏。
- `ChangeText` 改等宽数字。
- `SegmentPicker`：选中项改用语义色槽，选中文案加字重以强化层级。
- `HintRow`：空态/错误态主行动按钮由 OutlinedButton 改为金色填充 `Button`（修复空态 CTA 对比仅 ~1.5:1 的可用性问题）。

## 三、页面

### MarketScreen（首页）
- 列表行由低密度「价格另起一行」改为**对齐双列网格**：左 symbol｜右侧价格+涨跌幅右对齐块｜收藏。
- 成交额并入副标题（`现货 · 量 xxx`），信息密度与可扫描性提升；列表加细分隔线。
- 标题栏复用 `AppBar`。

### Detail / Alerts / Webhook / AlertEditor
- 顶部标题栏统一复用 `AppBar`，布局与留白一致。

## 四、模拟器实拍核验

- 行情列表：三列网格对齐正常、涨绿跌红正确、金色选中态 + 黑字对比约 12:1。
- 空态页：填充金色 CTA 可见，对比约 5:1；标题四级层级清晰。
- 遗留：空态说明文字对比约 3:1（次要信息，保留）。

## 五、发布

- 通过 GitHub Actions `release.yml`：裸版本号 tag `0.3.0` 触发，构建 debug APK 并上传 GitHub Release（附 SHA-256）。
- App 内更新按「去掉 v 前缀的 tag」与 versionName 比较，故 tag 与 versionName 一致。
