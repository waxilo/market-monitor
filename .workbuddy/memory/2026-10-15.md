## Android 端两条改动（发版 0.9.41）

### ① 切周期后纵轴重定：最新价居中且保全蜡烛

用户需求：切换周期时最新价可能落在可视窗口外（跨周期保留的全局纵向缩放/平移意图套到
新序列上，现价虚线与现价牌整个消失）。拍板（AskUserQuestion 二问）：
**居中且保全蜡烛**（以现价为中心对称外扩量程，宁可多一片空白不裁蜡烛）；
生效场景 = **切周期 + 换标的 + 首次进入**。

实现（`KlineChart.kt`，新增 `LaunchedEffect(symbolKey, interval.storageKey)`）：

- 新序列一就绪（`snapshotFlow` 等到非空蜡烛）就重算 `priceZoom` / `pricePan`：
  `halfSpan = max(close - low, high - close)`（到较远那侧极值的距离），
  `zoom = 2*halfSpan/baseSpan`（必 ≥1）、`pan = (close - center)/baseSpan`；
  既有钳制兜底：`scaled()` 的 `[0.08, 12]`、`panLimit` 的 `0.75`（常规场景 `|pan| ≤ 0.5` 打不满）。
- **量程不读 `liveAutoRange` 而按序列+视口现算**：序列从空变满那一刻协程在重算
  `autoRange` 的重组**之前** resume，读 `liveAutoRange` 拿到的还是空序列的 `(0,1)` 兜底，居中会锚错。
- 挂起抓取同理在转正前不读 `liveRangeBase` 之外的东西 —— 手势冻结期（`priceBase`）与此互斥，
  换周期/换标的会把 `priceBase` 重置回 null。
- 行为代价：纵向 `pricePan` 不再跨周期保留（每次切都按新序列重算）；`priceZoom` 也被覆盖。
  左下角「复位」小标仍在（zoom≠1 或 pan≠0 就显示）。

### ② 解锁态拖线改「长按才拖」

用户需求：全屏解锁态不小心划到线就被拖走。拍板：需要**按住线**才能拖。

实现（`detectChartGestures`）：

- down 仍就近判「抓哪根」（不判的话第一帧 MOVE 已滑出 24dp 抓取半径），但只**挂起**
  （`pendingHorizontal` / `pendingTrend`，`owned` 此时为 false）。
- 循环内挂起转正：单指按满系统长按时长且 `travelled ≤ touchSlop` → 置回原状态
  （`horizontalActive`/`trendMode=MOVE`）+ `owned=true`，落进 owned 分支逐帧拖；
  转正首帧即发拖线回调，「按住不动直接松手」照常落库。
- 滑出 slop 或落下第二根手指 → 挂起作废，这场照常平移/双指缩放，线纹丝不动
  （挂起期间不发任何拖线回调）。
- **轻点线从此什么都不发生**（旧版「点一下线就落一次库 + 垃圾桶亮一下」一并消失，
  android.md 里那段「有意保留」的取舍作废）。
- 工具模式（告警/水平/直线新建、删除模式）**不受影响**：有意操作，按下即响应。
- 与长按十字光标共用「时长 + slop」判定：按在线上转正拖线、按在空处出十字光标。
- `owned` 由 val 改 var：down 定性不变，解锁态转正后才置 true；`first.consume()` 判据
  `!onSubPane || owned` 对挂起场仍成立（主图起笔本就要抢，平移路径循环里照样消费）。

## 桌面端 0.1.26（macOS 点程序坞图标唤回大窗）

### Bug 与根因

用户报：macOS 上主窗关闭后台运行（收进托盘）后，**点 Dock 图标无法打开大窗，必须点任务栏**。
根因 = `lib.rs::run()` 尾部 `Builder::run(context)` **等价于事件回调空实现**；Dock 点击是系统直通
（AppKit `applicationShouldHandleReopen` → tao `RunEvent::Reopen`，`Focused` arm 兜不住隐藏窗），
没人接就毫无反应（托盘另有自己的事件路，所以托盘一直好使）。
修复 = `.build().run(|app, event| dock_reopen(app, &event))` 只接 Reopen → `to_main` 同一收口
（hide_mini + show_main，与重复启动/后台热键一致；不做 `has_visible_windows` 分支）。

### 真机验证（dev 身份 + 构建叠加层）

`.workbuddy/tmp/tauri-dock-test.json`（主窗 `visible:false` ⇒ 出生即后台态）+ `tauri.dev.conf.json`：

- 第 1 次 `open`：起实例、主窗隐藏（=后台态）；
- 第 2 次 `open`（点 Dock 等价物）：`DOCK-REOPEN-PROBE main_before=false main_after=true` ✅
- 第 3 次 `open`：`true/true` 幂等 ✅
- 全程 `SINGLE-INSTANCE-PROBE` 0 条（排除假阳性）✅；按 pid 只杀本次 dev 实例，用户正式版未动。
- 探针随后撤除（`cargo check` + `cargo test --lib` 11/11）。证据存 `.workbuddy/tmp/mm-dock-verify-1015.log`。
