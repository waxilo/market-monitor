# 2026-10-29

## 桌面端 UI 现代卡片化改版（0.1.47）

用户口径：「桌面端的页面 ui 都太老了，进行重构优化，我喜欢现代简洁风，使用卡片、圆角、阴影、动效等」。
之后按截图逐条收敛，几条改法值得记：

- **设计 token 全换**（`styles/theme.css` 顶部）：深色「深空灰」底 + 抬起的卡面，浅色「雾白」底 + 纯白卡面；
  圆角阶梯 6/10/14/18/22、三级阴影 + 内高光 `--ring`、`--fast/--base/--slow` 三档动效曲线。
  图表从 CSS 变量取色（`KlineCanvas` 的 `readPalette`），所以 `--paper / --wash / --hairline / --up / --down / --accent`
  这些名字**必须保留**，改名前先搜 `readPalette`。
- **顶栏不铺底板**（用户两次否掉「长条」和「三张卡」）：`.toolbar` 透明，左右两组 + 中间的搜索框各自是控件，
  行高 34px；搜索框只有一层 `--field` 淡底，聚焦才浮成实底 + 强调色描边。窗口控件与「设置/数据源」共用一条。
- **设置改成整页视图**（不再是 90% 固定弹窗）：`.settings-page` 铺满窗口，自带 34px 顶栏（返回 / 拖窗口 / 窗口控件）；
  主窗的 `WindowChrome` 在设置打开时**卸载**，避免两套 `.rz` 拉伸热区叠在窗口边缘。行情在底下保持挂载，返回不重拉。
- **指标栏**：`指标 MA EMA BOLL ＋`，配置用的「＋」放组末；EMA 分析入口搬到左侧栏底部小栏（`.list-foot`）。
  EMA 面板的开关提到 `App`（`emaOpen`），面板本体仍在 `ChartView`（它要读周期/均线/划线状态）。
- **图表读数改悬浮**：`chartHeights` 不再预留读数带高度（`mainTop` 恒为 0），读数叠在主图左上角，
  只在指针压在某根蜡烛上（`cross.onBar`）时出现，底下垫 86% 纸色圆角薄垫；移开即隐藏。
- **BOLL**：删掉上下轨之间的填充（`ChartSeries.bandFill` 整个字段移除），三条线统一 `OCTONARY` 中性灰蓝。
- ⚠️ **光标位图别再玩「与底色同色隐形」**：圆环光标原本画两枚同心环、各与一种主题底色同色，
  在浅色下里枚比卡面暗一点点 ⇒ 深色环里套一圈白环（用户连续两次反馈）。现在只用**一枚**中性灰环
  （`rgba(107,115,131,0.95)`），白底/深底都看得见；压在画线上的四角十字同理，只留一重笔画。
- 小眼睛图标（`EyeIcon`）瞳孔原本只有描边（SVG 根 `fill="none"`），13px 下是个空心环、看着像白点 ⇒ 改实心。
- 验证：`puppeteer-core` + 系统 Chrome 跑 `localhost:5173`（dev server 是用户起的，别关），
  1024 / 1280 / 2560 × 明暗两套逐屏截图；`npm run build` 每轮都过。
