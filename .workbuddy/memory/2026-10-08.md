## 2026-10-08 桌面端：悬浮窗切换后的黑色描边（DWM 焦点边框）
- 症状：主窗切悬浮窗瞬间，胶囊外多一圈 1px 黑边，点别处失焦才消失（用户截图）。
- 根因：Win11 给**持有焦点的前台顶层窗口**描一圈 DWM 边框；`to_mini` 里 `show() + set_focus()`
  让悬浮窗成为前台。`ShowWindow(SW_SHOW)` 本身就激活 ⇒ 「不抢焦点」修不掉。
- 修法：新建 `src-tauri/src/frame.rs`，`create_mini` 里调 `frame::clear_focus_border(&window)`——
  `DwmSetWindowAttribute(DWMWA_BORDER_COLOR, DWMWA_COLOR_NONE=0xFFFFFFFE)` 永久关掉这圈系统边框
  （悬浮窗自己的描边由 CSS 画）；Win11 专属 API，Win10 调用失败静默忽略（那边本没这圈边）；
  属性跟窗口生命周期一致，创建时设一次即可。焦点行为（快捷键兜底、awake 判据）不受影响。
- Cargo.toml windows features 补 `Win32_Graphics_Dwm`。cargo check + 11 条单测全绿。
- 真机验收留给用户（dev 跑起来切一次悬浮窗看边框是否消失）。
