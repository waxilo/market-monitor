## 桌面端：EMA 指标分析（约 15:20）

- 新增「EMA 分析」弹窗：`ChartView` 指标栏在均线「＋」与 BOLL 之间加一枚 chip（动作，不带 `.on` 态）；面板 `components/EmaAnalysisPanel.tsx`（`up-backdrop` / `up-panel up-wide`，同 MaPanel 弹窗骨架），纯函数 `lib/emaAnalysis.ts`（`emaWindow` / `lastEma` / `lastEmaOf` / `splitLevels` / `sideOf`）。
- 打开面板即按「EMA 族目录 × 周期条列表」并发 `fetchKlines`，逐档算末值 EMA，按最新价分「上方压力 / 下方支撑」两栏，点任意一行切到该 K 线周期并关面板。
- 取数根数以 `ChartView.HISTORY_BARS = 300` 为下限、最长档 +20、封顶 1000 —— 图上的线只画 300 根，若历史更长则 EMA 会与图上右端不一致，这条口径就是为了**同档只有一个数**。
- 压力 = EMA > 现价（升序，离得近的在前）、支撑 = 值 < 现价（降序）；**恰好等于现价的两边都不进**（否则出现零距离的假「最近」）；同价按「周期更细、档位更短」定序，避免列表随取数完成先后跳动。
- 两类失败分开报：「取数失败」（网络/数据源）vs「根数不够算不出这一档」（粗周期上的长档，如 1 月 EMA50）—— 混成一句会让人以为取数坏了。
- 现价跟 `ticker.lastPrice` 实时走，行情断了才回落成最细周期末根收盘并在抬头标「末根收盘价」；EMA 值是快照，靠「刷新」按钮重取。
- 配色沿用本 App 加密口径「绿涨红跌」：压力列 `--down`（红）、支撑列 `--up`（绿），不套 A 股红涨绿跌。
- 样式：`styles/theme.css` 末尾新增 `.ema-*`（面板宽 720、两列网格、行 5 列 grid：色点 / EMA档 / 周期小方框 / 价位右对齐 / 偏离%，<760px 竖排）；README「模块与现状」表加一行。
