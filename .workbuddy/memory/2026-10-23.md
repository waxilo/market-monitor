## 16:45 EMA 分析改成「静默刷新 + 面板开着每 1 分钟自动重算」

- 需求原话：①「点 ema 分析不清空刷新，而是静默刷新，只是右上角刷新按钮能看出来在刷新，获得新值再重绘」；
  ②「弹窗一直开启时，1 分钟自动刷新一次」。
- 数据从 4 个 state（levels/failures/missing/fallbackPrice）收成**一个 `EmaScan`**（`lib/emaAnalysis.ts`）——
  分开 set 会渲染出「新表配旧异常」的中间态。面板只留 `refreshing` 一个闸，**只喂按钮与首次加载文案，绝不拿来遮表格**。
- 快照缓存 `scanCache`（模块级 Map，按 `market|symbol|source|intervals|periods` 认，只留 6 份、先删再塞做 LRU）：
  面板一关就卸载，没它每次点开都要空等 11 个周期（实测首轮 **5.9s**）——用户要的「点开就有」靠它。
  换 key（切币/换源/改配置）时**立刻换成那一份的缓存**，不能留着上一个币的价位。
- 合并规则 `mergeEmaScan(prev, next)`（纯函数、有 22 项断言）：整段取数失败的周期**沿用上一轮各档**并记进 `stale`，
  提示语写成「（1时 显示的是上次的值）」；`missing` 的档上一轮算得出也沿用并从 missing 划掉；
  配置里删掉的档/周期**不会**被捡回来；兜底价 NaN 时也沿用。
- 自动刷新：`AUTO_REFRESH_MS = 60_000` 的 `setInterval` 只做 `setSeq(n => n + 1)`，与手动刷新共用同一条取数链路。
  ❗**别按「same scanKey 就跳过」去防并发**（第一版就是这么写的）：面板关掉重开时上一轮请求还在飞，
  新 effect 被跳过 → 而旧闭包的 `alive=false` 不会再 `setRefreshing(false)` ⇒ **按钮卡在「刷新中」直到 60s 后的下一跳**。
  现在不挡并发，旧轮次靠 `alive` 丢结果即可。
- 样式：`.ema-refresh { min-width: 62px }`（「刷新」↔「刷新中」不许把价位列推歪）；`updatedAt` 只进按钮 title（`上次 HH:MM:SS 更新`），不占版面。
- 验证：纯函数 **67 项**全绿（新增 22 项合并断言）；界面 `shoot-ema-silent.mjs` **16 项**全绿
  （1400×900 与 1024×680 各跑一遍，真链路不 mock）：刷新中行数 min=33 从未掉 0、无整块加载文案、
  重开首帧 33 行 + 按钮已「刷新中」、**等 71s/63s 实测自动刷新一轮**（时间戳 16:41:13 → 16:42:13）。

## 18:0x 画布指针：系统十字 → 空心圆环位图光标

- 改一处：`desktop/src/styles/theme.css` 的 `.chart-canvas` —— `cursor: crosshair` → 空心圆环 SVG data URI
  位图光标 `url("data:image/svg+xml,...") 10 10, crosshair`。热点在**环心**（`10 10`）⇒ 瞄准精度与十字一致；
  环心空腔直径 ~9.2px，蜡烛实体（默认 4~8px）能整个露出来。注释同步写进 CSS（取舍理由就在声明上方）。
- ❗关键约束：**光标位图吃不到 CSS 变量**（`url()` 里没有 `var()`），而项目有明暗两套主题 ⇒ 位图里画
  **两枚同心环**（21×21、圆心 `10,10`、`stroke-width 2`）：里枚浅 `rgba(238,240,243,0.95)` r=5.6（暗底显影）、
  外枚深 `rgba(12,13,15,0.62)` r=7.9（亮底显影）。两枚留 **0.3 空隙、不重叠** —— 叠着画在 1x 栅格上会出
  半透明糊边。**任何主题下看见的始终是一枚圆环**，不会变双圈（明暗两版截图已确认）。
- 为什么两枚同心，而不是「一枚描边套双色」：先写过一版（同一 r，深 3.6 打底 + 浅 1.4 压上），1x 下外圈
  只剩 **28/255** 的淡边，浅色主题几乎看不见；换成同心两枚后深环 alpha **158**、浅环 **242**。
- 兜底：声明的第二个值写 `crosshair` —— 位图（SVG data URI）解码失败时退回**系统十字**，而不是掉成箭头。
  `tauri.conf.json` 的 `csp` 是 `null`，data URI 不会被 CSP 拦。
- 验收脚本：`.workbuddy/tmp/verify-ring-cursor.mjs`（**7/7 通过**）。
  - ❗位图光标**截不进截图**（Chrome 从不把系统光标画进画面），所以**不能靠截图证明生效**。脚本改为从
    `theme.css` **抠出真实 cursor 声明**（不手抄）注入探针页，读 `getComputedStyle` + `CSS.supports`，
    再把 data URI 当 `<img>` 画进 canvas **按半径分桶**读像素：环心 r<4.0 必须 **alpha=0**、里枚 r4.6~6.7
    必须**浅且不透明**、外枚 r6.7~9.0 必须**深且不透明**、r>9.6 必须干净。
  - ❗坑一：用 `/url\(["']?(.+?)["']?\)/` 从声明里抠 data URI 会**在 `rgba(...)` 的括号处截断**（惰性匹配
