# 2026-11-22

## Android 0.9.78（vc 90）发版

用户三条反馈 + 一句「发布新版本」：纵坐标缩放时直线漂移 / 两点未选中不该展示 / 拖端点要能改角度 /
纵轴不显示 8000、9000 这种间隔刻度。全部落在 Android，桌面端这轮不动。

改动与根因见 `android.md` 的「直线的编辑入口也收成把手 + 纵轴刻度条数自适应」一节。要点：
- 直线与水平线同一个病 —— 线身可拖 + 长抓取带；改用三枚把手（两端改角度、中点平移），
  线身只选中；
- 端点只在选中态画；
- 刻度条数按可用高度自适应（主图 2~8、副图 2~3），小数位跟步长（step ≥ 1 一律整数）。

过程里的坑：
1. `detectChartGestures` 是 `PointerInputScope` 的扩展函数，**不是** composable 内部 lambda ——
   在它里面直接引用 `liveDrawLines` / `trendAnchorsOf` 全是 Unresolved reference，
   还附一句误导性的 `Restricted suspending functions can invoke member or extension suspending functions only on their restricted coroutine scope`。
   正确做法是把取值函数当参数传（`trendAnchors: (Long) -> Pair<TrendAnchor, TrendAnchor>?`）。
2. 单测 467 项全过（原 454 + TrendGripTest 7 + AxisDecimalsTest 6）；编译两次各 3~6 分钟，
   构建目录走 `.workbuddy/tmp` 重定向，没碰用户开着的 IDEA。
3. 发版仍走 `api-push-chain.py`（2 个提交，30 秒）+ API 建附注 tag `0.9.78`，
   `gh run watch` 2 分 40 秒成功，通道里只剩 `market-monitor-0.9.78.apk`。
4. ⚠️ **仍然没有真机验收**：`adb devices` 为空、MuMu 没起。三条都要用户装上后确认：
   选中直线 = 三枚带白心的点、按线身拖只平移图表、抓端点才改角度。

## 0.9.79：三处退回（直线选不中 / 漂移 / 纵轴刻度）

- **选不中**：命中按锚点段、绘制是延长线，两套几何 ⇒ 点延长段落空。新增 `clipLineToRect`
  （Liang–Barsky 无限直线版），绘制/命中/把手三处同源。
- **漂移**：双指落下没清 `trendMode`，抬一根手指后继续拖线并 commit；中点把手 20dp 在屏幕
  正中，拖量程的起手位一按就中。⇒ 双指作废抓线态 + 半径 12dp + 中点 ×0.72。
- **纵轴刻度**：上一版理解成「小数位要整数」，用户要的是「整列不要」。主图副图刻度标签
  与 `AXIS_LABEL_MIN_GAP_DP` 全删，网格线保留。
- 单测 475 全过（+`TrendClipTest` 8）。构建与产物待核对。
