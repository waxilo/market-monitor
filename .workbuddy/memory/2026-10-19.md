# 2026-10-19

## 双端：均线小眼睛（只藏不删）+ 发版 0.9.42 / 0.1.29

### 需求与语义（用户原话：「app和桌面端都在加一个小眼睛，能够显示、隐藏所有ma均线」）

- **只藏不删**：眼睛只控制绘制，不改变 MA 的选中子集。隐藏期间 chip 仍点亮，点回眼睛即恢复原来那几条。
  不要实现成「一键取消全选」——恢复时要逐条点回来。
- **隐藏范围**：均线折线与顶部 MA 读数行一起收掉（等效于 MA 列表为空）；BOLL、副图、画线不受影响。
- **视觉状态**：睁眼 = 可见（chip 常态）；斜杠眼 + chip 点亮 = 隐藏已启用（沿用桌面「画线眼睛」的语义）。
- **持久化**：桌面 `mm.indicators.maHidden`（缺省 false，容错解析）；App DataStore `ma_hidden`
  （`AppSettings.maHidden`，缺省 false），重启后保持。

### 实现

- 桌面（`desktop/src/lib/indicatorPrefs.ts`、`desktop/src/components/ChartView.tsx`）：
  `IndicatorPrefs` 加 `maHidden`；指标栏 MA chip 之后、「＋」之前加眼睛 chip（`aria-pressed` + `EyeIcon off`）；
  `KlineCanvas` 直接收 `maPeriods={maHidden ? [] : maPeriods}` —— 画布不用知道「隐藏」这回事，叠线与读数自然全关。
- App（`AppSettings.kt`、`SettingsDataStore.kt`、`DetailViewModel.kt`、`DetailScreen.kt`、`CommonUi.kt`）：
  `DetailUiState`/`ChartData` 加 `maHidden`；`toggleMaVisibility()` 立即更新 UI 并落 DataStore；
  `mainReadoutLines` 按 `if (maHidden) emptyList() else maPeriods` 算，骨架图与数据到达后的行数一致；
  竖屏与全屏两条 `ChartModel.build` 都喂 `visibleMa`；`FilterChip` 抽出 `ChipSurface`，新增同视觉的
  `IconChip`（带 contentDescription），眼睛用自绘 `EyeGlyph`（睁眼带瞳孔 / 闭眼加斜杠）。
- 位置：指标栏 MA chip 之后、「＋」之前；App 竖屏、全屏横屏与桌面工具条都有。

### 验证（发版前）

- App：MuMu 真机竖屏 + 全屏横屏；MA5/10/30 显示线与读数 → 点眼睛后线与读数消失、chip 仍选中、
  眼睛高亮斜杠 → 再点恢复；force-stop 重启后隐藏态保持。验证后已恢复原状态。
- 桌面：CDP 读 `KlineCanvas` fiber props，`maPeriods` 由 `[5,10,30]` → `[]`，MA chip 仍 `on`，
  眼睛 `aria-pressed=true`，localStorage `maHidden=true`，刷新持久；无头 Edge 出图核对显隐。
- 本地构建：App `assembleDebug` + `testDebugUnitTest` 绿；桌面 `tsc --noEmit` + `vite build` 绿
  （产物 `index-CoWRGNKG.js` / `index-CcguxJRN.css`）。
