## 双端：Bitget K 线取不回来（周期码大小写 / utc 对齐 / 90 天深度）

### 症状

用户报「Bitget 的 K 线图没取到」：桌面端选 Bitget 数据源、周期 **16 时**（自定义周期）时，图表显示
「K 线没取回来 · 网络或数据源不通」。

### 根因：`granularity` 大小写敏感

Bitget v2 `/api/v2/mix/market/candles` 的 `granularity` 是**大小写敏感的白名单**，服务端原文：

```
[1m,3m,5m,15m,30m,1H,4H,6H,12H,1D,1W,1M,6Hutc,12Hutc,1Dutc,3Dutc,1Wutc,1Mutc]
```

原代码写成小写 `1h/2h/4h/6h/12h/1d/3d/1w/1M` ⇒ **小时及以上全部被拒**，返回
`HTTP 200 + {"code":"400171","msg":"Parameter verification failed k-line time range should be [...]"}`。
所以 1m/3m/5m/15m/30m 一直正常、**小时档从来没成功过**；16 时这种聚合周期用 4H 打底，于是必然失败。

附带发现：`2h`（120m）与 `3d`（4320m）在 Bitget **没有原生码**（白名单里没有 `2H`，3 天只有 `3Dutc`）
⇒ 从 ladder 删掉 120，4320 改指向原生 `3Dutc`。

### 对齐口径：粗档统一取 utc 变体

Bitget 非 utc 档按 **UTC+8** 对齐（实测 `1D` 起点 `16:00Z`、`6H` 起点 `10:00Z`），而聚合是
`floor(ts/目标周期)` 分桶 ⇒ **只有 UTC 边界才是 epoch 整数倍**。所以：

- 粗档统一取 utc 变体：`6Hutc / 12Hutc / 1Dutc / 3Dutc / 1Wutc / 1Mutc`；
- `1H` / `4H` **不用** utc 变体（+8h 是它们的整数倍，边界本来重合）。

最终 ladder（桌面 `desktop/src/lib/dialects.ts` 的 bitget 与 Android `FuturesDialects.kt` 的
`BitgetDialect` **两边同步**）：`1m/3m/5m/15m/30m` + `60:'1H' 240:'4H' 360:'6Hutc' 720:'12Hutc'
1440:'1Dutc' 4320:'3Dutc' 10080:'1Wutc' 43200:'1Mutc'`。

### 另：历史深度有服务端上限（与 limit 无关）

4H 最多 **540 根**、1D **90 根**、1W **13 根**、1M **4 根** ⇒ 约等于只有**最近 90 天**；1H 可 1000 根。
所以粗周期「往更早翻页」会提前耗尽（上层按空页停翻，行为正常，不要当 bug 修）。
`endTime` 参数实测有效，可翻旧页。

### 顺带：取数失败别再只说「网络或数据源不通」

`desktop/src/components/ChartView.tsx`：失败时把方言层抛出的**真实原因**显示出来（截断 64 字 + `title`
放全文）。这次就是因为笼统提示，病灶（400171）完全不可见。

### 回归脚本与跑法（可复用）

`desktop/.workbuddy/tmp/probe-dialects-live.mjs` —— Node 22 原生 strip-types 直接 import
`src/lib/dialects.ts`，用**真接口**逐周期断言 URL 与解析：

```
cd desktop && NODE_USE_ENV_PROXY=1 HTTPS_PROXY=http://127.0.0.1:7897 \
  node --experimental-strip-types .workbuddy/tmp/probe-dialects-live.mjs
```

- `ONLY=BITGET,BYBIT` 可过滤；POST 必须带 `content-type`，否则 Hyperliquid 回 **415**。
- 本次全量跑完：8 家方言，除 Bitget 外原本就都合法（Bybit / OKX / Gate / MEXC / HTX / Hyperliquid 全绿）；
  Bitget 修复后 **13 个原生周期全通**，16h 聚合落 **135 根**且全部落在 16h 桶边界。
- ⚠️ 本机 `api.bitget.com` **直连不通**（curl exit 35），须走代理 `http://127.0.0.1:7897`；
  Node 侧用 `NODE_USE_ENV_PROXY=1`（22.22.2 可用，会带 UNDICI-EHPA 实验警告）。

### 追加：每条均线自己的小眼睛（同一天，用户提的）

需求原话：「设置均线时可以单独设置小眼睛」。于是显隐做成**两级、正交**：
- **总闸** = 指标栏那枚族 chip（`hidden`），管「这一族参不参与绘图」；
- **分闸** = 面板里每行行尾的小眼睛（`muted: number[]`，只藏不删），管「族开着时这一条画不画」。
- 关键语义：**族关掉再打开，分闸状态原样保留**（总闸不动分闸）；图上画的 = `catalog − muted`。
- 不变量 `muted ⊆ catalog` 由 `normalizeMuted` 守：删行时必须同步剔除，否则「删了又加回来」会莫名不显示。
- 族 chip 的置灰判据从「目录条数」改成「**可见条数**」（全被小眼睛藏起时点亮也画不出东西）。

两端落点：
- 桌面：`maPeriods.ts` 加 `normalizeMuted / drawnPeriods / toggleMuted / setAllMuted`，
  `MaFamilyPrefs.muted`；`indicatorPrefs` 缺省 `[]`（老存档观感不变）；`MaPanel` 行内 `.ma-eye`
  + 标题行「全部显示 / 全部隐藏」+ 页签 `画X / 共Y 条`；`ChartView` 的 `visibleFamilies` 用 `drawnPeriods`。
  眼睛图标抽成 `components/EyeIcon.tsx`（原在 ChartView 内私有，现在面板也要用）。
- Android：`DetailViewModel.kt` 里同名四个纯函数；`AppSettings.maMuted/emaMuted` + DataStore
  keys `ma_muted / ema_muted`（CSV）；`saveCatalog(family, catalog, colors, muted)` 多一个参数；
  `MaDraft` 加 `muted`；`IndicatorBar.maCount` 传 `visiblePeriods().size`。
  眼睛图标从 `KlineChart.kt` 的私有 `EyeGlyph` 抽到 `ui/common/EyeGlyph.kt`（`glyphSize` 参数，
  不能叫 `size` —— `DrawScope.size` 同名会让 lambda 里的解析含糊）。
