# 最新价虚线补价格标签

日期：2026-09-21
涉及版本：0.9.7（versionCode 19）
改动文件：

- `ui/chart/KlineChart.kt`

需求原文：

> 图表上。当前价格的线应该显示价格标签

---

## 一、问题

图上那条横贯绘图区的虚线（`drawLastPrice`，画在最新一根的收盘价高度）只有线没有读数。
右侧价格刻度是 1-2-5 阶梯（`ValueRange.gridLines`），最近的一条刻度离最新价往往还有一段距离，
用户只能目测估个大概 —— 而「现在多少钱」正是这条线唯一要回答的问题。

## 二、改动

### 1. 新增 `LastPriceBadge`

```kotlin
val last: Kline = series.candles.lastOrNull() ?: return
val y = geo.yOf(range.toFraction(last.closeDouble()), geo.mainTopPx, geo.mainHeightPx)
if (y !in geo.mainTopPx..(geo.mainTopPx + geo.mainHeightPx)) return
PriceTag(yPx = y, ..., accent = if (last.close >= last.open) upColor else downColor)
```

关键点：

- **换算链与 `drawLastPrice` 完全一致**（`toFraction` → `yOf`），所以标签上的数字就是虚线所指的价位；
- **显示条件也一致**：量程被纵向缩放/平移把最新价挤出主图时，虚线与标签一起消失，
  不会剩下一个没有线可指的孤立数字；
- 底色用画蜡烛那两支 `upColor` / `downColor`，与虚线永远同色。

### 2. `PriceTag` 增加可选底色 `accent`

```kotlin
/** 标签底色。默认中性墨色 —— 十字光标与告警线都跟涨跌无关；最新价传涨跌色。 */
accent: Color? = null
...
.background(accent ?: colors.ink)
```

十字光标、告警线两个标签行为不变（仍走默认的 `ink` 底 + `paper` 字）。

### 3. 挂载顺序

放在 `PriceAxisLabels` **之后**、`CrosshairPriceBadge` / `AlertLinePriceBadge` **之前**：

- 之后 —— 它要盖住同高的那条刻度文字（交易软件的通行做法：最新价标签替代该处刻度）；
- 之前 —— 十字光标与告警线标签跟着手指走，被压住就看不见了。
